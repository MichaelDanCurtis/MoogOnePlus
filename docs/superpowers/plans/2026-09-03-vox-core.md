# Vox Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A bridge on the Mac that serves a touch-first web UI over the LAN and lets Mac or iPad control the Moog One's SuperCollider effects live, decode MPE / poly-aftertouch into per-voice events, and route any source to any destination — with every control badged by what this session actually verified on hardware.

**Architecture:** `moogone.vox` is a package of pure modules (fx, mpe, router, destinations, meters, protocol) glued by one asyncio bridge (`websockets` for the UI, the existing `ScClient`/`UdpTransport` for scsynth, `rtmidi` for MIDI). Everything testable runs against `MockScsynth` and fake ports; nothing claims *live* that was not seen live.

**Tech Stack:** Python ≥3.11, `websockets` ≥13 (asyncio API), `python-rtmidi` ≥1.5, the repo's own `moogone.osc` / `moogone.sc` / `moogone.transport` / `moogone.mock`, pytest, ruff. UI is one static HTML file, vanilla JS, no build step.

## Global Constraints

- Python `>=3.11` (pyproject). No new required dependencies: `websockets` and `python-rtmidi` go in an **optional** group `vox`.
- Every UI-facing control carries a badge: `live` (verified on hardware this session), `untested` (plausible, never run), `blocked` (needs a discovery step) — copied from the spec's "Decisions" table. `live` is assigned **only** to: scsynth `n_set` / `g_queryTree` on port 57110, and the four `/a/stat/*` meter reads.
- `/n_set` is never acknowledged. A value is reported *confirmed* only after a tree re-read shows it. "Sent" and "confirmed" are distinct states.
- The synth is **off** tonight. No task may claim hardware verification. The morning checklist (Task 9) is where that happens.
- Tests must discriminate: each module includes at least one test that fails if the logic is wrong, not merely one that passes when it is right.
- `ruff check` and `ruff format --check` clean after every task. Full suite green.
- Commit after every task. Do not push (the owner pushes).

## Corrections to the spec, made while planning

- The spec says meters poll at "~15 Hz". The meters live on the voice bus, reachable only via SSH to the box — at roughly one query per second with the existing tooling. Task 6 builds the meter source with a `MockMeterSource` for tonight and an `SshMeterSource` badged **untested**; the real rate is measured in the morning, not asserted now.
- The spec's "17 effect nodes" includes the two routers. `nodes_from_tree` returns every `SynthNode`; the UI counts what it is given.

`src/moogone/vox/protocol.py`:

```python
"""The JSON messages that cross the WebSocket between bridge and UI.

Every message is one JSON object with a ``type``. ``REQUIRED`` lists the keys each type
must carry; a message missing one is rejected here rather than becoming a half-formed
command downstream. The UI is a browser on an iPad — it will send whatever it sends, and
the bridge is the last place a malformed request can be refused cleanly.
"""

from __future__ import annotations

import json
import math
from dataclasses import dataclass

BADGE_STATES = ("live", "untested", "blocked")


class ProtocolError(ValueError):
    pass


@dataclass(frozen=True)
class Badge:
    """What this session actually verified about a control. See the spec's Decisions table."""

    state: str
    why: str = ""

    def __post_init__(self) -> None:
        if self.state not in BADGE_STATES:
            raise ValueError(f"badge state must be one of live, untested, blocked; got {self.state!r}")
        if self.state != "live" and not self.why.strip():
            raise ValueError(f"a {self.state!r} badge must say why")

    def as_dict(self) -> dict:
        return {"state": self.state, "why": self.why}


LIVE = Badge("live", "")


def UNTESTED(why: str) -> Badge:  # noqa: N802 — reads as a constant at call sites
    return Badge("untested", why)


def BLOCKED(why: str) -> Badge:  # noqa: N802
    return Badge("blocked", why)


#: Required keys per message type, both directions. Anything else is rejected.
REQUIRED: dict[str, tuple[str, ...]] = {
    # UI -> bridge
    "fx.list": (),
    "fx.set": ("node", "ctl", "value"),
    "route.add": ("src", "dst"),
    "route.remove": ("id",),
    "route.list": (),
    "mpe.config": ("zone",),
    "midi.note": ("note", "on"),
    "ping": (),
    # bridge -> UI
    "fx.tree": ("nodes",),
    "fx.value": ("node", "ctl", "value", "state"),
    "meters": ("values",),
    "mpe.event": ("kind", "voice", "note", "value"),
    "routes": ("routes",),
    "badge": ("path", "state", "why"),
    "status": ("sc", "midi_in", "midi_out", "meters"),
    "error": ("where", "what"),
    "pong": (),
}


def encode(msg: dict) -> str:
    if "type" not in msg:
        raise ProtocolError("message has no type")
    if msg["type"] not in REQUIRED:
        raise ProtocolError(f"unknown message type {msg['type']!r}")
    _check_finite(msg)
    return json.dumps(msg, separators=(",", ":"))


def decode(text: str) -> dict:
    try:
        obj = json.loads(text)
    except (TypeError, ValueError) as exc:
        raise ProtocolError(f"not JSON: {exc}") from exc
    if not isinstance(obj, dict):
        raise ProtocolError("message must be a JSON object")
    kind = obj.get("type")
    if not isinstance(kind, str):
        raise ProtocolError("message has no string 'type'")
    if kind not in REQUIRED:
        raise ProtocolError(f"unknown message type {kind!r}")
    missing = [k for k in REQUIRED[kind] if k not in obj]
    if missing:
        raise ProtocolError(f"{kind} is missing required field(s): {', '.join(missing)}")
    return obj


def _check_finite(obj) -> None:
    if isinstance(obj, float) and not math.isfinite(obj):
        raise ProtocolError("numbers must be finite; NaN/Infinity are not valid JSON")
    if isinstance(obj, dict):
        for v in obj.values():
            _check_finite(v)
    elif isinstance(obj, (list, tuple)):
        for v in obj:
            _check_finite(v)
```

`src/moogone/vox/fx.py`:

```python
"""The SuperCollider effects as a control surface.

This is the one part of Vox that stands on a path verified on hardware this session:
``/g_queryTree`` and ``/n_set`` against ``scsynth`` on 57110. Everything here is badged
``live`` for that reason and no other.

``/n_set`` is fire-and-forget. :meth:`FxWorkbench.confirm` re-reads the tree and compares;
a value is *confirmed* only when the server says it holds it. That distinction — sent
versus confirmed — is carried all the way to the UI.
"""

from __future__ import annotations

from dataclasses import dataclass

from ..sc.client import ScClient
from ..sc.tree import GroupNode, SynthNode

# Range inference by control name. Values observed on the live tree: mix/feedback/tone/pan
# sit in 0..1; gain-family controls have been seen at 0.98 and 1.0 with headroom expected;
# times are seconds (timeL 0.0416 = 41.6 ms). Bus indices are not for turning.
_UNIT = {"mix", "wet", "dry", "feedback", "tone", "ctl", "pan", "offset"}
_GAIN = {"gain", "g_in", "g_out", "volume"}
_SWITCH = {"enable"}
_READONLY_SUFFIX = ("bus", "in", "out")


@dataclass(frozen=True)
class ControlSpec:
    name: str
    value: float
    lo: float
    hi: float
    kind: str  # "range" | "switch" | "readonly"


@dataclass(frozen=True)
class FxNodeInfo:
    node_id: int
    defname: str
    controls: tuple[ControlSpec, ...]


def infer_range(name: str, value: float) -> tuple[float, float, str]:
    n = name.lower()
    if n in _SWITCH:
        return 0.0, 1.0, "switch"
    if n in _UNIT:
        return 0.0, 1.0, "range"
    if n in _GAIN:
        return 0.0, 2.0, "range"
    if n.startswith("time"):
        return 0.0, 2.0, "range"
    if n.endswith(_READONLY_SUFFIX) and n not in _UNIT:
        return float(value), float(value), "readonly"
    # Unknown: bracket the current value with room above it, never a zero-width range.
    hi = max(1.0, 2.0 * abs(float(value)))
    lo = min(0.0, float(value))
    return lo, hi, "range"


def nodes_from_tree(root: GroupNode) -> list[FxNodeInfo]:
    out: list[FxNodeInfo] = []

    def walk(node) -> None:
        if isinstance(node, SynthNode):
            specs = tuple(
                ControlSpec(name, float(v), *infer_range(name, float(v)))
                for name, v in node.controls.items()
            )
            out.append(FxNodeInfo(node.node_id, node.defname, specs))
        elif isinstance(node, GroupNode):
            for child in node.children:
                walk(child)

    walk(root)
    return out


class FxWorkbench:
    def __init__(self, client: ScClient):
        self._client = client
        self._nodes: list[FxNodeInfo] = []

    def refresh(self, timeout: float = 2.0) -> list[FxNodeInfo]:
        self._nodes = nodes_from_tree(self._client.query_tree(timeout=timeout))
        return self._nodes

    @property
    def nodes(self) -> list[FxNodeInfo]:
        return self._nodes

    def set(self, node_id: int, name: str, value: float) -> None:
        """Send. This proves nothing about the server; see :meth:`confirm`."""
        self._client.n_set(node_id, **{name: float(value)})

    def confirm(
        self, node_id: int, name: str, expected: float, tol: float = 1e-4, timeout: float = 2.0
    ) -> tuple[bool, float | None]:
        """Re-read the tree. Returns (took, value_seen). Raises if the server cannot be read —
        a server that does not answer is not a server that confirmed."""
        for n in self.refresh(timeout=timeout):
            if n.node_id == node_id:
                for c in n.controls:
                    if c.name == name:
                        return abs(c.value - float(expected)) <= tol, c.value
                return False, None
        return False, None
```

"""MPE and poly-aftertouch decoding.

The discriminating cases: pressure on the wrong channel, a stolen voice, and a master-channel
message that must fan out to every note in the zone.
"""

import pytest

from moogone.vox.mpe import MpeDecoder, NoteEvent, VoiceTracker, ZoneConfig


def on(ch, note, vel=100):
    return [0x90 | ch, note, vel]


def off(ch, note):
    return [0x80 | ch, note, 0]


def chan_pressure(ch, p):
    return [0xD0 | ch, p]


def poly_pressure(ch, note, p):
    return [0xA0 | ch, note, p]


def cc(ch, num, val):
    return [0xB0 | ch, num, val]


def bend(ch, value14):
    return [0xE0 | ch, value14 & 0x7F, (value14 >> 7) & 0x7F]


class TestVoiceTracker:
    def test_allocates_lowest_free_voice(self):
        t = VoiceTracker(4)

```python
"""MPE and polyphonic-aftertouch decoding into per-voice events.

Two input dialects, one output:

- **Poly aftertouch** (``0xA0 note pressure``) is keyed by note number. Cleanest for a
  hammer-action keybed with per-key pressure, which is what the S88 provides.
- **MPE** spreads notes across member channels. Pressure (``0xD0``), slide (CC 74) and bend
  (``0xE0``) arrive on the member channel of the note they belong to. The **master**
  channel addresses every note in the zone at once.

Voice tracking is ours: this is the "take over" branch of the per-voice-pressure spec's
Phase 3. Note-on allocates the lowest free voice; when all are busy the oldest is stolen
and an ``off`` is emitted for the victim so downstream state never dangles.
"""

from __future__ import annotations

from dataclasses import dataclass, field

KINDS = ("on", "off", "pressure", "slide", "bend")


@dataclass(frozen=True)
class ZoneConfig:
    zone: str = "lower"  # "lower" | "upper"
    members: int = 15
    bend_range: float = 48.0  # semitones, MPE member default

    @property
    def master(self) -> int:
        return 0 if self.zone == "lower" else 15

    @property
    def member_channels(self) -> frozenset[int]:
        if self.zone == "lower":
            return frozenset(range(1, 1 + self.members))
        return frozenset(range(15 - self.members, 15))


@dataclass(frozen=True)
class NoteEvent:
    kind: str
    voice: int
    note: int
    value: float  # velocity/pressure/slide 0..1; bend -1..1; off 0
    channel: int


@dataclass
class VoiceTracker:
    n_voices: int = 16
    _voice_note: dict[int, int] = field(default_factory=dict)  # voice -> note
    _order: list[int] = field(default_factory=list)  # voices in allocation order (oldest first)

    def voice_for(self, note: int) -> int | None:
        for v, n in self._voice_note.items():
            if n == note:
                return v
        return None

    def allocate(self, note: int) -> int:
        existing = self.voice_for(note)
        if existing is not None:
            return existing
        free = [v for v in range(self.n_voices) if v not in self._voice_note]
        if free:
            v = free[0]
        else:
            v = self._order.pop(0)  # steal the oldest
        self._voice_note[v] = note
        if v in self._order:
            self._order.remove(v)
        self._order.append(v)
        return v

    def release(self, note: int) -> int | None:
        v = self.voice_for(note)
        if v is None:
            return None
        del self._voice_note[v]
        self._order.remove(v)
        return v

    def active(self) -> dict[int, int]:
        return dict(self._voice_note)


class MpeDecoder:
    def __init__(self, zone: ZoneConfig | None = None, n_voices: int = 16):
        self.zone = zone or ZoneConfig()
        self.tracker = VoiceTracker(n_voices)
        self._channel_note: dict[int, int] = {}  # member channel -> note currently on it

    def feed(self, data: bytes | list[int]) -> list[NoteEvent]:
        b = list(data)
        if not b:
            return []
        status = b[0]
        if status >= 0xF0:
            return []
        kind, ch = status & 0xF0, status & 0x0F
        if kind in (0x90, 0x80, 0xA0, 0xB0, 0xE0) and len(b) < 3:
            return []
        if kind == 0xD0 and len(b) < 2:
            return []

        if kind == 0x90 and b[2] > 0:
            return self._note_on(ch, b[1], b[2] / 127.0)
        if kind == 0x80 or (kind == 0x90 and b[2] == 0):
            return self._note_off(ch, b[1])
        if kind == 0xA0:
            v = self.tracker.voice_for(b[1])
            return [] if v is None else [NoteEvent("pressure", v, b[1], b[2] / 127.0, ch)]
        if kind == 0xD0:
            return self._per_channel("pressure", ch, b[1] / 127.0)
        if kind == 0xB0 and b[1] == 74:
            return self._per_channel("slide", ch, b[2] / 127.0)
        if kind == 0xE0:
            raw = (b[2] << 7) | b[1]
            return self._per_channel("bend", ch, (raw - 8192) / 8191.0 if raw > 8192 else (raw - 8192) / 8192.0)
        return []

    # -- helpers ------------------------------------------------------------

    def _note_on(self, ch: int, note: int, vel: float) -> list[NoteEvent]:
        out: list[NoteEvent] = []
        victim = None
        if self.tracker.voice_for(note) is None and len(self.tracker.active()) >= self.tracker.n_voices:
            victim_voice = self.tracker._order[0]
            victim = self.tracker.active()[victim_voice]
        v = self.tracker.allocate(note)
        if victim is not None:
            out.append(NoteEvent("off", v, victim, 0.0, self._channel_of(victim, ch)))
            self._forget_channel(victim)
        self._channel_note[ch] = note
        out.append(NoteEvent("on", v, note, vel, ch))
        return out

    def _note_off(self, ch: int, note: int) -> list[NoteEvent]:
        v = self.tracker.release(note)
        self._forget_channel(note)
        return [] if v is None else [NoteEvent("off", v, note, 0.0, ch)]

    def _per_channel(self, kind: str, ch: int, value: float) -> list[NoteEvent]:
        if ch == self.zone.master:
            return [
                NoteEvent(kind, v, n, value, ch)
                for v, n in sorted(self.tracker.active().items())
            ]
        if ch not in self.zone.member_channels:
            return []
        note = self._channel_note.get(ch)
        if note is None:
            return []
        v = self.tracker.voice_for(note)
        return [] if v is None else [NoteEvent(kind, v, note, value, ch)]

    def _channel_of(self, note: int, default: int) -> int:
        for c, n in self._channel_note.items():
            if n == note:
                return c
        return default

    def _forget_channel(self, note: int) -> None:
        for c, n in list(self._channel_note.items()):
            if n == note:
                del self._channel_note[c]
```

```python
"""Source → destination routing: the patch bay behind the cables.

Sources are string keys with values in 0..1 (bend arrives −1..1 and is remapped by the
caller). Each route scales into ``[lo, hi]`` through a curve, optionally inverted and
slewed. :meth:`Router.tick` returns only the writes whose value **changed**, and never
more than one write per destination per ``min_interval`` — coalescing to the latest.
Without both rules a 200 Hz tick would hammer scsynth with identical ``/n_set``s.
"""

from __future__ import annotations

import itertools
from dataclasses import dataclass, field

CURVES = {
    "lin": lambda x: x,
    "exp": lambda x: x * x * x,
    "log": lambda x: 1.0 - (1.0 - x) ** 3,
    "s": lambda x: x * x * (3.0 - 2.0 * x),
}


@dataclass
class Route:
    id: str
    src: str
    dst: str
    lo: float = 0.0
    hi: float = 1.0
    curve: str = "lin"
    slew: float = 0.0  # seconds to traverse the full [lo, hi] span; 0 = immediate
    invert: bool = False

    def __post_init__(self) -> None:
        if self.curve not in CURVES:
            raise ValueError(f"curve must be one of {', '.join(CURVES)}; got {self.curve!r}")


@dataclass
class _State:
    current: float | None = None  # last slewed output
    last_sent: float | None = None
    pending: float | None = None
    last_time: float = -1e9


_ids = itertools.count(1)


class Router:
    def __init__(self, min_interval: float = 0.02):
        self.min_interval = min_interval
        self._routes: dict[str, Route] = {}
        self._route_state: dict[str, _State] = {}
        self._dst_last_time: dict[str, float] = {}
        self._dst_pending: dict[str, float] = {}

    def add(self, route: Route) -> str:
        if not route.id:
            route.id = f"r{next(_ids)}"
        self._routes[route.id] = route
        self._route_state[route.id] = _State()
        return route.id

    def remove(self, route_id: str) -> bool:
        if route_id not in self._routes:
            return False
        del self._routes[route_id]
        del self._route_state[route_id]
        return True

    def routes(self) -> list[Route]:
        return list(self._routes.values())

    def tick(self, sources: dict[str, float], dt: float, now: float) -> list[tuple[str, float]]:
        targets: dict[str, float] = {}
        for rid, r in self._routes.items():
            if r.src not in sources:
                continue
            x = min(1.0, max(0.0, float(sources[r.src])))
            if r.invert:
                x = 1.0 - x
            y = r.lo + (r.hi - r.lo) * CURVES[r.curve](x)
            st = self._route_state[rid]
            if r.slew > 0 and st.current is not None:
                max_step = abs(r.hi - r.lo) * dt / r.slew
                delta = y - st.current
                y = st.current + max(-max_step, min(max_step, delta))
            st.current = y
            targets[r.dst] = y

        writes: list[tuple[str, float]] = []
        for dst, y in targets.items():
            last_t = self._dst_last_time.get(dst, -1e9)
            if now - last_t < self.min_interval:
                self._dst_pending[dst] = y  # hold; latest wins
                continue
            last_sent = self._dst_last_value(dst)
            if last_sent is not None and abs(y - last_sent) < 1e-9:
                self._dst_pending.pop(dst, None)
                continue
            writes.append((dst, y))
            self._dst_last_time[dst] = now
            self._dst_pending.pop(dst, None)
            self._set_last_value(dst, y)

        # Flush anything held whose window has now expired and that is no longer targeted
        for dst, y in list(self._dst_pending.items()):
            if dst in targets:
                continue
            if now - self._dst_last_time.get(dst, -1e9) >= self.min_interval:
                writes.append((dst, y))
                self._dst_last_time[dst] = now
                self._set_last_value(dst, y)
                del self._dst_pending[dst]
        return writes

    # last-sent per destination lives on any route that targets it; keep it on the router
    def _dst_last_value(self, dst: str) -> float | None:
        return getattr(self, "_last_vals", {}).get(dst)

    def _set_last_value(self, dst: str, y: float) -> None:
        if not hasattr(self, "_last_vals"):
            self._last_vals: dict[str, float] = {}
        self._last_vals[dst] = y
```

"""Where a routed value can go, and how honestly each path is labelled.

Only :class:`ScParam` is ``live`` — the one path this session verified on hardware. MIDI
out from the Mac and raw OSC to ``las-sc`` are ``untested``: plausible, never run.
:class:`VoiceParam` is ``blocked``: the per-voice write address is unknown, and the
experiment that finds it is written into the badge so the UI can show it.
"""

from __future__ import annotations

from collections.abc import Callable
from typing import Protocol

from ..osc import OscMessage
from .protocol import BLOCKED, LIVE, UNTESTED, Badge

GO_NO_GO = (
    "Hold one note on the synth. Send the candidate per-voice write to move that one "
    "voice's filter cutoff. If exactly one voice in a held chord changes timbre, the "
    "per-voice path exists and this becomes one config value. Until then no per-voice "
    "write is sent."
)


class Destination(Protocol):
    badge: Badge

    def write(self, path: str, value: float) -> bool: ...


class ScParam:
    badge = LIVE

    def __init__(self, fx):
        self._fx = fx

    def write(self, path: str, value: float) -> bool:
        parts = path.split(".")
        if len(parts) != 3 or parts[0] != "sc":
            return False
        try:
            node = int(parts[1])
        except ValueError:
            return False
        self._fx.set(node, parts[2], float(value))
        return True


class _MidiBase:
    badge = UNTESTED(
        "MIDI from the Mac to the synth has not been proven. MIDI was only ever sent from "
        "the box's own ALSA. Cable check: Komplete Audio 6 DIN out -> Moog DIN in."
    )

    def __init__(self, port, channel: int = 0):
        self._port = port
        self._ch = channel & 0x0F


def _u7(value: float) -> int:
    return max(0, min(127, int(round(float(value) * 127))))


class MidiCC(_MidiBase):
    def write(self, path: str, value: float) -> bool:
        parts = path.split(".")
        if len(parts) != 3 or parts[:2] != ["midi", "cc"]:
            return False
        try:
            cc = int(parts[2])
        except ValueError:
            return False
        if not 0 <= cc <= 127:
            return False
        self._port.send_message([0xB0 | self._ch, cc, _u7(value)])
        return True


class MidiNote(_MidiBase):
    def write(self, path: str, value: float) -> bool:
        parts = path.split(".")
        if len(parts) != 3 or parts[:2] != ["midi", "note"]:
            return False
        try:
            note = int(parts[2])
        except ValueError:
            return False
        if not 0 <= note <= 127:
            return False
        if float(value) >= 0.5:
            self._port.send_message([0x90 | self._ch, note, 100])
        else:
            self._port.send_message([0x80 | self._ch, note, 0])
        return True


class RawOsc:
    badge = UNTESTED(
        "Writes to las-sc / the voice bus were accepted but never audible this session. "
        "Sent as a single float argument."
    )

    def __init__(self, send: Callable[[bytes], None]):
        self._send = send

    def write(self, path: str, value: float) -> bool:
        if not path.startswith("osc."):
            return False
        address = "/" + path[4:].replace(".", "/")
        self._send(OscMessage(address, [float(value)]).encode())
        return True


class VoiceParam:
    badge = BLOCKED(GO_NO_GO)

    def write(self, path: str, value: float) -> bool:
        return False


class Dispatcher:
    def __init__(self):
        self._dests: list[tuple[str, Destination]] = []

    def register(self, prefix: str, dest: Destination) -> None:
        self._dests.append((prefix, dest))
        self._dests.sort(key=lambda p: -len(p[0]))  # longest prefix first

    def _find(self, path: str) -> Destination:
        for prefix, dest in self._dests:
            if path.startswith(prefix):
                return dest
        raise KeyError(f"no destination registered for {path!r}")

    def badge_for(self, path: str) -> Badge:
        return self._find(path).badge

    def write(self, path: str, value: float) -> tuple[bool, Badge]:
        dest = self._find(path)
        return dest.write(path, value), dest.badge

"""The four output meters — the one continuous read the synth genuinely gives us.

``/a/stat/{mainl,mainr,send1,send2}`` each return two floats: min and max sample excursion
over the window. Verified live this session, idle floor −90 to −118 dBFS. They are on the
voice bus, reachable only from the box, so the real source is an SSH batch — which has
not been run as a loop and is badged accordingly. :class:`MockMeterSource` exists so the
UI can be built and previewed tonight without pretending.
"""

from __future__ import annotations

import math
import random
import subprocess
from typing import Protocol

from ..vx import interpret, parse_hexdump, render_remote_command
from .protocol import UNTESTED, Badge

METER_ADDRESSES = ("/a/stat/mainl", "/a/stat/mainr", "/a/stat/send1", "/a/stat/send2")


class MeterSource(Protocol):
    badge: Badge

    def read(self) -> dict[str, tuple[float, float]] | None: ...


def to_dbfs(lo: float, hi: float) -> float:
    peak = max(abs(lo), abs(hi))
    return -math.inf if peak == 0 else 20.0 * math.log10(peak)


def parse_meter_batch(text: str) -> dict[str, tuple[float, float]]:
    out: dict[str, tuple[float, float]] = {}
    for row in text.splitlines():
        if "\t" not in row:
            continue
        addr, _, hexdump = row.partition("\t")
        addr = addr.strip()
        try:
            reply = interpret(addr, parse_hexdump(hexdump))
        except (ValueError, TypeError):
            continue
        if reply.kind != "value" or len(reply.args) < 2:
            continue
        try:
            out[addr] = (float(reply.args[0]), float(reply.args[1]))
        except (TypeError, ValueError):
            continue
    return out


class MockMeterSource:
    badge = UNTESTED("synthetic meter data for building the UI; not the instrument")

    def __init__(self, seed: int = 0):
        self._rng = random.Random(seed)
        self._level = {a: 0.001 for a in METER_ADDRESSES}

    def read(self) -> dict[str, tuple[float, float]]:
        out = {}
        for a in METER_ADDRESSES:
            self._level[a] = max(1e-6, min(0.9, self._level[a] * self._rng.uniform(0.7, 1.4)))
            v = self._level[a]
            out[a] = (-v * self._rng.uniform(0.6, 1.0), v * self._rng.uniform(0.6, 1.0))
        return out


class SshMeterSource:
    badge = UNTESTED(
        "reads the four live getters over SSH in one batch; never run as a loop. "
        "Real update rate is measured in the morning, not asserted."
    )

    def __init__(self, device: str, wait: int = 1):
        self._device = device
        self._wait = wait

    def script(self) -> str:
        lines = []
        for a in METER_ADDRESSES:
            lines.append(f'printf "%s\\t" "{a}"; {render_remote_command(a, wait=self._wait)}; echo')
        return "\n".join(lines)

    def read(self) -> dict[str, tuple[float, float]] | None:
        try:
            proc = subprocess.run(
                [
                    "ssh",
                    "-o", "StrictHostKeyChecking=no",
                    "-o", "UserKnownHostsFile=/dev/null",
                    "-o", "ConnectTimeout=5",
                    f"root@{self._device}",
                    "sh",
                ],
                input=self.script(),
                capture_output=True,
                text=True,
                check=False,
                timeout=len(METER_ADDRESSES) * (self._wait + 1) + 10,
            )
        except (subprocess.TimeoutExpired, OSError):
            return None
        got = parse_meter_batch(proc.stdout)
        return got or None

        static_dir: pathlib.Path | None = None,
        meter_period: float = 0.5,
        tick_hz: float = 100.0,
    ):

        self._static = static_dir or STATIC
        self._meters = meters
        self._meter_period = meter_period
        self._tick = 1.0 / tick_hz
        self._clients: set = set()
        self._sc_ok = False

        self._client = ScClient(UdpTransport(sc_host, sc_port))
        self.fx = FxWorkbench(self._client)
        self.mpe = MpeDecoder()

        self.sources: dict[str, float] = {}

        self.dispatcher = Dispatcher()
        self.dispatcher.register("sc.", ScParam(self.fx))
        self.dispatcher.register("voice.", VoiceParam())
        self.dispatcher.register("osc.", RawOsc(self._client.send_raw if hasattr(self._client, "send_raw") else self._send_raw))
        self._midi_out = midi_out
        if midi_out is not None:
            self.dispatcher.register("midi.cc.", MidiCC(midi_out))
            self.dispatcher.register("midi.note.", MidiNote(midi_out))
        self._midi_in_name = midi_in_name

    # -- transport helpers ---------------------------------------------------
    def _send_raw(self, data: bytes) -> None:

    # -- HTTP for the UI -----------------------------------------------------
    def _http(self, connection, request):

            return None

            resp = connection.respond(HTTPStatus.OK, body)
            resp.headers["Content-Type"] = "text/html; charset=utf-8"
            return resp
        return connection.respond(HTTPStatus.NOT_FOUND, "not found\n")

        async with serve(self.handle, host, port, process_request=self._http) as server:
            self.port = server.sockets[0].getsockname()[1]
            loops = [
                asyncio.create_task(self._meter_loop()),
                asyncio.create_task(self._router_loop()),
            ]
            if self._midi_in_name:
                loops.append(asyncio.create_task(self._midi_loop()))
            try:
                await server.serve_forever()
            finally:
                for t in loops:
                    t.cancel()
                    with contextlib.suppress(asyncio.CancelledError):
                        await t

    async def handle(self, ws) -> None:
        self._clients.add(ws)
        try:
            await ws.send(encode(self._status()))
            async for text in ws:
                try:
                    msg = decode(text)
                except ProtocolError as exc:
                    await ws.send(encode({"type": "error", "where": "protocol", "what": str(exc)}))
                    continue
                for out in await asyncio.to_thread(self.dispatch, msg):
                    await ws.send(encode(out))
        finally:
            self._clients.discard(ws)

    async def _broadcast(self, msg: dict) -> None:
        text = encode(msg)
        for ws in list(self._clients):
            with contextlib.suppress(Exception):
                await ws.send(text)

    # -- request dispatch (runs in a thread; scsynth I/O is blocking) --------
    def dispatch(self, msg: dict) -> list[dict]:
        t = msg["type"]
        if t == "ping":
            return [{"type": "pong"}]
        if t == "fx.list":
            return [self._fx_tree()]
        if t == "fx.set":
            return self._fx_set(int(msg["node"]), str(msg["ctl"]), float(msg["value"]))
        if t == "route.add":
            r = Route(
                str(msg.get("id", "")),
                str(msg["src"]),
                str(msg["dst"]),
                float(msg.get("lo", 0.0)),
                float(msg.get("hi", 1.0)),
                str(msg.get("curve", "lin")),
                float(msg.get("slew", 0.0)),
                bool(msg.get("invert", False)),
            )
            try:
                self.router.add(r)
            except ValueError as exc:
                return [{"type": "error", "where": "route.add", "what": str(exc)}]
            b = self.dispatcher.badge_for(r.dst) if self._has_dest(r.dst) else None
            out = [self._routes()]
            if b is not None and b.state != "live":
                out.append({"type": "badge", "path": r.dst, **b.as_dict()})
            return out
        if t == "route.remove":
            self.router.remove(str(msg["id"]))
            return [self._routes()]
        if t == "route.list":
            return [self._routes()]
        if t == "mpe.config":
            self.mpe = MpeDecoder(
                ZoneConfig(
                    str(msg["zone"]),
                    int(msg.get("members", 15)),
                    float(msg.get("bend_range", 48.0)),
                )
            )
            return [self._status()]
        if t == "midi.note":
            ok, badge = (False, None)
            if self._has_dest("midi.note."):
                ok, badge = self.dispatcher.write(f"midi.note.{int(msg['note'])}", 1.0 if msg["on"] else 0.0)
            out = []
            if badge is not None:
                out.append({"type": "badge", "path": "midi.note", **badge.as_dict()})
            if not ok:
                out.append({"type": "error", "where": "midi.note", "what": "no MIDI out configured"})
            return out
        return [{"type": "error", "where": "dispatch", "what": f"unhandled {t}"}]

    def _has_dest(self, path: str) -> bool:
        try:
            self.dispatcher.badge_for(path)
            return True
        except KeyError:
            return False

    def _fx_tree(self) -> dict:
        try:
            nodes = self.fx.refresh()
            self._sc_ok = True
        except (ScError, ScTimeout, OSError) as exc:
            self._sc_ok = False
            return {"type": "error", "where": "scsynth", "what": f"cannot read node tree: {exc}"}
        return {
            "type": "fx.tree",
            "nodes": [
                {
                    "id": n.node_id,
                    "defname": n.defname,
                    "controls": {
                        c.name: {
                            "value": c.value,
                            "lo": c.lo,
                            "hi": c.hi,
                            "kind": c.kind,
                            "badge": LIVE.as_dict(),
                        }
                        for c in n.controls
                    },
                }
                for n in nodes
            ],
        }

    def _fx_set(self, node: int, ctl: str, value: float) -> list[dict]:
        self.fx.set(node, ctl, value)
        out = [{"type": "fx.value", "node": node, "ctl": ctl, "value": value, "state": "sent"}]
        try:
            ok, seen = self.fx.confirm(node, ctl, value)
        except (ScError, ScTimeout, OSError) as exc:
            out.append({"type": "fx.value", "node": node, "ctl": ctl, "value": value, "state": "unconfirmed"})
            out.append({"type": "error", "where": "scsynth", "what": f"confirm failed: {exc}"})
            return out
        out.append(
            {
                "type": "fx.value",
                "node": node,
                "ctl": ctl,
                "value": seen if seen is not None else value,
                "state": "confirmed" if ok else "unconfirmed",
            }
        )
        return out

    def _routes(self) -> dict:
        return {"type": "routes", "routes": [r.__dict__ for r in self.router.routes()]}

    def _status(self) -> dict:
        return {
            "type": "status",
            "sc": self._sc_ok,
            "midi_in": bool(self._midi_in_name),
            "midi_out": self._midi_out is not None,
            "meters": self._meters.badge.as_dict(),
        }

    # -- background loops ----------------------------------------------------
    async def _meter_loop(self) -> None:
        while True:
            values = await asyncio.to_thread(self._meters.read)
            if values:
                for a, (lo, hi) in values.items():
                    self.sources[f"meter.{a.rsplit('/', 1)[-1]}"] = min(1.0, max(abs(lo), abs(hi)))
                await self._broadcast({"type": "meters", "values": {k: list(v) for k, v in values.items()}, "badge": self._meters.badge.as_dict()})
            await asyncio.sleep(self._meter_period)

    async def _router_loop(self) -> None:
        last = time.monotonic()
        while True:
            now = time.monotonic()
            dt, last = now - last, now
            for dst, val in self.router.tick(self.sources, dt, now):
                if self._has_dest(dst):
                    await asyncio.to_thread(self.dispatcher.write, dst, val)
            await asyncio.sleep(self._tick)

    async def _midi_loop(self) -> None:
        import rtmidi  # optional dependency; only needed when a port is named

        midi_in = rtmidi.MidiIn()
        names = midi_in.get_ports()
        idx = next((i for i, n in enumerate(names) if self._midi_in_name in n), None)
        if idx is None:
            await self._broadcast({"type": "error", "where": "midi", "what": f"no MIDI in matching {self._midi_in_name!r}; have {names}"})
            return
        midi_in.ignore_types(sysex=True, timing=True, active_sense=True)
        midi_in.set_callback(lambda ev, _=None: self._midi_q.put(ev[0]))
        midi_in.open_port(idx)
        try:
            while True:
                try:
                    data = self._midi_q.get_nowait()
                except queue.Empty:
                    await asyncio.sleep(0.002)
                    continue
                for e in self.mpe.feed(data):
                    key = f"mpe.{e.kind}[{e.voice}]"
                    self.sources[key] = (e.value + 1.0) / 2.0 if e.kind == "bend" else e.value
                    if e.kind == "off":
                        for k in ("pressure", "slide", "bend"):
                            self.sources.pop(f"mpe.{k}[{e.voice}]", None)
                    await self._broadcast({"type": "mpe.event", "kind": e.kind, "voice": e.voice, "note": e.note, "value": e.value})
        finally:
            midi_in.close_port()


def main() -> None:
    p = argparse.ArgumentParser(description="Vox — bridge between a browser and the Moog One")
    p.add_argument("--mock", action="store_true", help="run against an in-process mock scsynth")
